# Мёртвые фразы и кальки русской технической прозы: одна регулярка на строку,
# `#` — комментарий, пустые строки игнорируются. Читается правилом `forbid_file`
# и правится человеком: это редакторская политика, а не код.
#
# Список ОДИН для тех, кто пишет, и для тех, кто судит. Копия списка внутри
# пайплайна или внутри промпта — это два списка после первой правки.
#
# Флаг по умолчанию `i`, поэтому регистр писать не нужно.
