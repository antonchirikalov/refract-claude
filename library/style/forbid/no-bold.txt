# Форматирование, а не словарь: это верно для любого языка, поэтому список
# отдельный от `ru-slop.txt` — статья на английском получает его же.
#
# Жирный шрифт внутри абзаца — самый заметный признак машинного текста: модель
# расставляет его как замену интонации, которой в прозе нет. Заголовки жирными
# не размечают, для них есть `#`.

# **жирный** внутри строки. Не задевает `**` в блоках кода: правило `prose_chars`
# и стилист смотрят прозу, а этот паттерн ищет пару звёздочек вокруг текста.
\*\*[^*\n]{1,200}\*\*

# __жирный__ — второй синтаксис того же
__[^_\n]{1,200}__

# Дефис в роли тире: пробел-дефис-пробел в прозе. Начала строк-списков («- пункт»)
# не задеваются, потому что там перед дефисом нет пробела.
\S - \S
